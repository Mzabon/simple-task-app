# 나의 작업 관리 v0.8 — 배포 패키지

기존 v0.7 앱을 업데이트하기 위한 **완성형 정적 PWA 패키지**입니다. GitHub Pages 저장소의 루트에 있는 파일과 `icons` 폴더를 이 패키지의 파일로 교체합니다.

## 포함 파일

```
index.html
sw.js
manifest.webmanifest
icons/
  icon-48.png
  icon-180.png
  icon-192.png
  icon-512.png
  icon-maskable-512.png
README.md
```

## 배포 방법 (GitHub Codespaces)

1. **기존 코드와 데이터를 먼저 확인하세요.** 업무 데이터는 GitHub가 아니라 지금 사용 중인 스마트폰/태블릿의 localStorage에 저장됩니다. 배포 전에 앱을 삭제하거나 브라우저 데이터(사이트 데이터)를 지우지 마세요.
2. ZIP 압축을 해제하고, `index.html`, `sw.js`, `manifest.webmanifest`를 Codespaces의 저장소 루트에 **덮어씁니다**.
3. ZIP의 `icons` 폴더 안의 PNG 5개를 저장소 `icons` 폴더에 업로드해 같은 이름의 파일을 교체하고, 기존에 없던 파일은 추가합니다.
4. 변경된 파일이 모두 저장되었는지 확인하고 Codespaces의 **명령을 받을 수 있는 새 터미널**에서 아래 명령어를 한 줄씩 실행하세요.

```bash
git add index.html sw.js manifest.webmanifest icons README.md
git commit -m "Release task app v0.8"
git push origin main
```

※ `README.md`까지 저장소로 옮기지 않았다면 첫 명령어에서 `README.md`만 빼고 실행해도 됩니다. 터미널에서 `git status`로 변경 파일을 확인할 수 있습니다.

5. GitHub Pages 배포를 확인한 후 **기존에 설치된 앱을 인터넷에 연결하여 다시 실행**하세요. 기존 앱을 제거하거나 다시 설치할 필요는 없습니다. 새로운 아이콘은 Android 런처가 캐시할 수 있어 적용에 시간이 더 걸릴 수 있습니다.
6. 테스트용 업무를 하나 만들어 **달력 날짜 다시 탭, 종류별 점, 설정 화면, 다크모드, 백업 다운로드** 기능을 확인합니다.

## 데이터 보존과 백업

- 기존의 `simple-task-v2` 업무 저장 키, `simple-task-categories-v1` 종류, `simple-task-category-colors-v1` 색상 저장 키는 유지합니다.
- 이전 버전 업무에 `categoryId`, `updatedAt`만 추가하여 향후 동기화에 대비합니다.
- 새 `미분류` 종류는 삭제된 종류의 업무를 보관하기 위한 기본값이며 기존 '내 일' 등은 유지됩니다.
- 설정 → 데이터 관리 → **백업 파일 저장**에서 JSON을 내려받습니다.
- 설정 → 데이터 관리 → **백업 파일 선택**으로 가져오면 **현재 기기의 업무 데이터를 통째로 교체**합니다. 잘못된 파일은 적용하지 않으며 가져오기 전에 확인창이 표시됩니다.
- 다른 기기에서 자동으로 동기화되지는 않습니다. 기기 간 업무 이전이 필요하면 JSON을 내보내고 해당 기기에서 가져오세요.
- 스마트폰에서 크롬 사이트 데이터/앱 저장 공간을 삭제하면 업무가 지워질 수 있으므로 중요한 업무는 정기적으로 백업하세요.

## 새 기능

- 선택 날짜를 다시 누르면 해당 날짜를 마감일로 입력한 새 업무 창 열기
- 달력에 카테고리별 색상 점 (종류당 하나, 최대 4개 + 나머지 개수)
- 독립된 설정 화면: 종류 추가·이름변경·색상변경·삭제 / 데이터 백업·복원 / 라이트·다크·자동 테마 / 앱 정보
- 사용자 제공 아이콘 5종 적용 및 별도 maskable 아이콘 등록
- 새 버전 확인 및 업데이트 안내 UI. **v0.7→v0.8 첫 업데이트는 기존 v0.7 앱에 알림 UI가 없어 기존 방식대로 적용될 수 있습니다.** 다음 버전부터 대기형 서비스 워커로 배포해야 '업데이트' 버튼을 누르는 동작이 실질적으로 작동합니다.
- v0.7의 완료 기록, 스와이프, 정렬, 월 이동 등 유지

## 기술 참고

정적 HTML/CSS/JS 및 서비스 워커만 사용하며 클라우드 서버나 Supabase는 연결되어 있지 않습니다. 브라우저 지원에 따라 백업 파일의 저장 위치가 달라질 수 있습니다.
